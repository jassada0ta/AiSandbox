# System Architecture

## Tech stack

### Frontend
 - Programming Language: JavaScript
 - Frontend Framework: React
 - User View-Hooks pattern to implement React components

### Backend
 - Programming Language: JavaScript
 - Use Strapi as the backend platform to manage content and data
 - Content type in Strapi are as follows:
   - PurchaseOrderHeader: Represents Purchase Orders header information, including details such as order number, customer information, and order date.
   - PurchaseOrderLineItem: Represents Purchase Order Line Items, including details such as product information, quantity, and pricing.
